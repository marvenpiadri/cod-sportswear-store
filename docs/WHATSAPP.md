# WhatsApp handoff

The store keeps the owner's WhatsApp number in international format. Checkout optionally collects a separate customer WhatsApp number. After an order is saved, the customer can open WhatsApp with the order reference and summary prefilled, then actively send the message to the owner.

The CRM order archive also provides a direct customer-contact shortcut using the customer's WhatsApp number (falling back to their phone number) with a short order-confirmation message prefilled. This is a user-driven WhatsApp link, not automated messaging. Do not claim messages were sent or delivered without a WhatsApp API integration.
